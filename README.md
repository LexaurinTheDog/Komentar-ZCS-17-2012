# Komentář k zákonu č. 17/2012 Sb., o Celní správě České republiky

Otevřený komentář k zákonu o Celní správě České republiky — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; Generální ředitelství cel a celní úřady, zvláštní ustanovení o řízení, povinnosti a oprávnění celníků, operativně pátrací a donucovací prostředky, přestupky, zpracování údajů a mezinárodní spolupráce.
